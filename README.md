# NL2SQL Assistant — Документация PM/BA проекта

Проект по разработке документации для AI-ассистента **NL2SQL (Natural Language to SQL)** — системы, позволяющей пользователям получать данные из базы данных с помощью запросов на естественном языке.

---

## Ключевая идея

### Проблема

Бизнес-команды зависят от разработчиков и аналитиков, когда им необходимо получить данные из базы. Это замедляет принятие решений и увеличивает нагрузку на технических специалистов.

### Решение

Разработать AI-ассистента, который переводит вопросы пользователей на естественном языке в SQL-запросы, обеспечивая быстрый, безопасный и удобный доступ к данным.

### Ожидаемый эффект

- Сокращение времени получения данных
- Снижение нагрузки на аналитиков и разработчиков
- Ускорение принятия бизнес-решений
- Возможность самостоятельной работы с данными для нетехнических пользователей
- Повышение эффективности использования корпоративных данных

**Цель:** предоставить бизнес-пользователям возможность получать информацию из базы данных без знания SQL.

---

## Контекст

Во многих компаниях данные хранятся в реляционных базах данных, однако доступ к ним требует знания SQL или участия технических специалистов.

NL2SQL Assistant устраняет этот барьер, позволяя задавать вопросы обычным языком, а система автоматически преобразует их в корректные SQL-запросы.
